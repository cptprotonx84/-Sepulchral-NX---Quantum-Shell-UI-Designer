The interface reflects the exact stylistic DNA found in the `NX-DARK LABS` display spec:
1.  **Unified Matrix Grid**: A dense modular 7x9 grid alignment structure.
2.  **Geometric Angles**: All stroke diagonals cut strictly at $22.5^{\circ}$.
3.  **Squared Curves**: Arcs rendered as clean squared corners instead of smooth circular sweeps.
4.  **Tactile Imperfections**: Closed forms contain subtle 1px gaps or offsets to simulate old-school plotter calibration offsets.

## 🖥️ Windows Local Installation Guide

To clone, build, and run the system locally on any Windows workstation (Windows 10 / Windows 11):

### Prerequisites
1.  **Node.js**: Download and install the LTS (Long-Term Support) version from [nodejs.org](https://nodejs.org/). This installer automatically configures `npm`.
2.  **Git** *(Optional)*: Download and install [Git for Windows](https://git-scm.com/) to easily clone repositories and push commits.

---

### Step-by-Step Setup

1.  **Get the Source Files**:
    *   *Option A (Git)*: Open Git Bash or PowerShell and clone the project:
        ```bash
        git clone <YOUR_GITHUB_REPO_URL>
        cd <REPO_NAME>
        ```
    *   *Option B (ZIP)*: Extract the ZIP archive, open Command Prompt (`cmd`) or PowerShell, and change directories to the root:
        ```cmd
        cd C:\path\to\extracted\folder
        ```

2.  **Install Node Dependencies**:
    Initialize the local `node_modules` environment by running:
    ```bash
    npm install
    ```

3.  **Run the App in Development Mode**:
    Execute the following command to boot the local Vite server:
    ```bash
    npm run dev
    ```
    Once loaded, click the local URL in the terminal (typically `http://localhost:3000`) to view the interactive shaper in your web browser.

4.  **Compile for Production**:
    Assemble an optimized production bundle of static assets into the `dist/` directory:
    ```bash
    npm run build
    ```
    To preview this production build locally on Windows, run:
    ```bash
    npm run preview
    ```

## 🚀 GitHub Deployment (How to Push)

Prepare and push your local workspace commits to your personal GitHub repository:

```bash
# 1. Initialize Git in the project root folder
git init

# 2. Add all source files (Vite automatically ignores node_modules/ via .gitignore)
git add .

# 3. Create the initial commit
git commit -m "feat: initialize Sepulchral Labs terminal shaper workspace"

# 4. Set the active branch to main
git branch -M main

# 5. Link your local repo to your remote repository on GitHub
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git

# 6. Push your commits to GitHub
git push -u origin main
```
